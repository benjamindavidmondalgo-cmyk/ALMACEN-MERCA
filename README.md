## 1. RESUMEN

El presente proyecto propone el desarrollo de un sistema de registro y búsqueda de documentos para la empresa VICMAR, con la finalidad de facilitar la organización y recuperación de facturas y guías de remisión relacionadas con los movimientos de prendas terminadas. Actualmente, la empresa utiliza principalmente documentos físicos, por lo que localizar información específica puede requerir tiempo y esfuerzo.

La solución se desarrollará utilizando el lenguaje de programación C#. El sistema permitirá registrar movimientos de mercadería, seleccionar archivos de facturas o guías de remisión en formato PDF o imagen, almacenarlos en carpetas organizadas y guardar la información necesaria para encontrarlos posteriormente.

Además, contará con opciones para registrar movimientos, visualizar los registros, buscar documentos por código o número, ordenar la información y guardar los datos en un archivo de texto local. De esta manera, se busca mejorar el orden documental y reducir el tiempo dedicado a la búsqueda manual, utilizando conceptos básicos de programación como variables, condicionales, estructuras repetitivas, listas, funciones y manejo de archivos.
